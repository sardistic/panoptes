Panoptes API

Keyed, rate-limited access to the data behind the map: open hazard and environment feeds relayed through one shared cache, and what Panoptes computes from them, including fused events, incident-rate surges and radio activity. Keys are free and issued by hand to approved applicants.

Quick start

Send your key in the X-API-Key header (or Authorization: Bearer …). Never put it in a URL.

curl -H "X-API-Key: pk_…" https://panoptes.run/v1/data/usgs_quakes?max_age_hours=6

Every answer has the same envelope. Show the attribution wherever you display the data.

{
  "dataset": "usgs_quakes",
  "attribution": "U.S. Geological Survey",
  "licence": "Public domain (U.S. Government work)",
  "served_at": 1763769600.0,
  "data": [ … ]
}
GET /v1/datasetsThe catalogue, with licences and parameters. No key needed.
GET /v1/data/{dataset}Current data. Unknown query parameters are ignored.
GET /v1/data/event/{id}One fused event's history.
GET /v1/meYour tier, limits, today's usage and 30 days of history.

Datasets

Open feeds are relayed exactly as Panoptes holds them, so each source sees no more traffic because of you. Derived datasets are computed by Panoptes. Some sources are on the map but cannot be redistributed; they are listed at the end with the reason. Datasets marked non-commercial come from sources whose licence forbids commercial use.

    Limits and errors

    Each response carries X-RateLimit-Remaining and X-Quota-Remaining. Going over the per-minute rate returns 429 with Retry-After. Using up the daily quota returns 429 until 00:00 UTC. Identical requests within a dataset's refresh window are served from cache (X-Cache: HIT), so polling faster than the refresh interval gains nothing. Statuses you may see: 401 no or bad key · 403 dataset not granted to your key · 404 unknown dataset · 502 an upstream source failed.

    Apply for a key

    Applications are read by a person. Say what you are building and why. You will get an email when you apply and another when it is decided. Approved applicants collect their key from a private link in that email.
